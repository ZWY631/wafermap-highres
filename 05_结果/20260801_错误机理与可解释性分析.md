# 2026-08-01 错误机理与可解释性分析

## 1. 分析范围

本报告只分析已经冻结并完成的结果，不重新训练模型、不调整阈值、不修改测试集。结果来源包括：

- 五模型三随机种子统一测试；
- HighRes、标准 ShuffleNetV2、ResNet18 三模型三随机种子鲁棒性实验；
- 固定测试集上的错误形态量化；
- 固定协议下的 Grad-CAM；
- 三随机种子测试预测的事后错误统计。

报告中的“机理”指从统计结果和模型敏感区域中提出的工程解释，不等同于物理因果机制，也不等同于缺陷定位精度。

## 2. 主要错误集中在哪里

HighRes ShuffleNetV2 在干净固定测试集上的平均结果为：Accuracy 98.0342%，Macro-F1 90.2029%，Balanced Accuracy 89.1150%。总体准确率较高，但 Macro-F1 和 Balanced Accuracy 明显低于 Accuracy，原因是 `none` 类占测试集 22,117/25,943（约 85.25%），整体 Accuracy 会被多数类强烈影响。

按类别三种子平均错误率排序，困难类别为：

| 类别 | 三种子平均错误率 | 三种子一致判为 none |
|---|---:|---:|
| Loc | 26.65% | 13.54% |
| Scratch | 21.42% | 11.73% |
| Edge-Loc | 16.24% | 10.28% |
| Donut | 11.24% | 1.20% |
| Center | 8.44% | 6.21% |
| Random | 7.44% | 0.77% |
| Edge-Ring | 1.29% | 0.07% |
| Near-full | 4.76% | 0% |
| none | 0.49% | 不适用 |

三种子均错误的样本为 381 个，其中 359 个三种子都预测为同一个错误类别。最主要错误对为：

- Edge-Loc -> none：三种子一致错误 80 个，约占 Edge-Loc 样本的 10.28%；
- Loc -> none：三种子一致错误 73 个，约占 Loc 样本的 13.54%；
- Center -> none：三种子一致错误 40 个，约占 Center 样本的 6.21%；
- Scratch -> none：三种子一致错误 21 个，约占 Scratch 样本的 11.73%。

这说明当前模型最主要的失败形式不是把一种缺陷稳定地错分成另一种缺陷，而是把弱、稀疏或形态不典型的缺陷判成无缺陷 `none`。这里的“平均错误率”是三个冻结模型中错误预测比例的均值，“三种子一致判为 none”是更严格的共同错误统计；两者不能混用。该结果与类别不均衡和缺陷信号相对背景较弱的工程现象一致，但只能作为结果驱动的解释，不能写成已证明的因果结论。

## 2.1 错误形态量化

对固定测试集中的 3,826 张 non-none 图，使用 failed-die 电测状态计算 failed-die fraction、连通分量数、最大连通分量占比、singleton-fail fraction、component-size CV 和空间位置统计。Loc、Scratch、Edge-Loc 的最大连通分量占比分别为 34.82%、22.18%、33.24%，而 Edge-Ring 为 58.77%；Scratch 的 singleton-fail fraction 为 12.26%。这些指标描述的是 Bin Map 的电测几何，不是光学缺陷像素或物理缺陷面积。

按类别百分位进行相关性分析后，最大连通分量占比与三种子错误率 rho=-0.265，component-size CV 与错误率 rho=-0.289，failed-die fraction 与错误率 rho=-0.117，spatial dispersion 与错误率 rho=+0.126。相关性均为探索性关联，不代表物理因果；Near-full 测试支持仅 21 张，相关结果不稳定。

## 3. 鲁棒性结果说明什么

相对于干净测试集，HighRes 三种子平均 Macro-F1 的下降为：

| 扰动 | 轻度 | 中度 | 重度 |
|---|---:|---:|---:|
| 旋转 | +0.16 pp | -0.57 pp | -0.20 pp |
| 平移 | -0.81 pp | -9.48 pp | -21.74 pp |
| 局部缺损 | -1.01 pp | -3.71 pp | -9.75 pp |
| bin flip | -2.00 pp | -8.72 pp | -16.16 pp |

模型对小角度旋转相对稳定，说明其分类主要依赖整体形状而非严格的像素方向。对重度平移最敏感，说明有效缺陷位置与晶圆整体坐标、边缘结构或裁剪边界之间存在较强关系。局部缺损和 bin flip 会破坏稀疏缺陷的空间连续性，因此 Macro-F1 下降明显。

三模型横向汇总（12 个条件的等权平均）为：HighRes 的平均 Macro-F1 为 84.0367%，平均下降 6.1662 pp；标准 ShuffleNetV2 为 72.9510%，下降 7.5437 pp；ResNet18 为 80.9721%，下降 7.9534 pp。HighRes 在总体和重度平移下更稳定，但在 bin flip 上不是最优，因此不能宣称普遍鲁棒。这里的扰动是仿真压力测试，不代表真实产线的全部噪声分布；不能直接把下降幅度宣称为真实设备上的性能下降。

## 4. Grad-CAM 观察

Grad-CAM 使用冻结的 HighRes ShuffleNetV2 seed 42、输入尺寸 64×64、目标层 `network.conv5[0]`，样本按冻结协议选择：Edge-Loc、Loc、Scratch 各选择一张正确分类的中位置信度样本和一张三种子一致误判为 `none` 的第 50 百分位样本。

正确分类样本的 CAM 通常覆盖晶圆内部或边缘的较大区域，而不是一个可直接对应到单个缺陷像素的框。这只能说明模型对这些空间区域较敏感，不能说明模型完成了缺陷定位。WM-811K 没有与类别标签独立的像素级缺陷区域标注，因此不计算 CAM-IoU；把输入中的 failed-die 状态直接当作定位真值会造成循环论证。

三个误判样本对预测类别 `none` 的 CAM 在指定目标层上均为全零；同一误判样本对真实缺陷类别的 CAM 均为非零。该现象已经通过对 `network.conv5[0]`、`network.conv5[1]` 和 `network.conv5[2]` 的只读梯度诊断确认：全零现象发生在协议指定的卷积输出层，而不是保存图片时被截断。因此论文中应如实写成：

> 在固定目标层下，误判为 `none` 的预测目标没有形成非零的正梯度响应；这表明该层对这些样本的 `none` 判别难以通过标准 Grad-CAM 给出有辨识度的空间响应。真实类别目标仍产生非零响应，但该响应不等价于定位能力。

不要把黑色的预测 `none` CAM 解释成“模型没有关注任何区域”，也不要根据热力图反推物理缺陷成因。

## 5. 可用于论文的工程结论

1. 仅报告 Accuracy 会掩盖少数缺陷类别的不足，应同时报告 Macro-F1、Balanced Accuracy、按类召回率和混淆矩阵。
2. 后续优化的优先对象是 Loc、Scratch、Edge-Loc 到 `none` 的漏检，而不是继续追求多数类 `none` 的总体准确率。
3. 数据增强应优先覆盖平移、局部缺损和 bin flip 引起的分布变化，但增强强度必须通过验证集选择，不能用固定测试集调参。
4. Grad-CAM 适合做模型敏感区域的定性审计；若要声称缺陷定位，需要额外的像素级或框级标注和定位指标，本项目目前没有这类证据。
